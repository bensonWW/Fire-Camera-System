# 基於 FreeRTOS 的雙核邊緣智慧消防監控系統

本專案採用最新的 **Raspberry Pi Pico 2 W (RP2350)** 微控制器開發板，結合 **FreeRTOS** 即時作業系統，打造一款兼具「硬即時救災響應」與「數位隱私保護」的固定式邊緣智慧消防攝影機。

## 📌 專案核心功能
- **事件驅動安全抓拍 (Snapshot)**：平時不進行連續影像串流，降低記憶體開銷並保護個人隱私。僅在火災觸發或消防一線人員遠端驗證成功時，解開軟體級隱私鎖，進行現場 JPEG 影像抓拍並上傳。
- **雙核心平行運作 (SMP)**：利用 Pico 2 W 的雙核心優勢，將高即時性的感測器監控與高資源消耗的網路/影像傳輸進行核心隔離。
- **即時聲響變紅告警**：室內聲音感測器（呼救聲、爆炸聲）一旦超標，立刻透過 MQTT 協定使網頁端主控台對應之攝影機外框秒變紅色（Red Alert）。
- **多管道遠端通知**：火災發生時，系統透過 Webhook 自動發送緊急通知 Email。

## 🏗️ FreeRTOS 任務與多核心分工架構

系統透過 FreeRTOS 排程器管理多個任務（Tasks），並利用佇列（Queue）與信號量（Semaphore）進行執行緒安全（Thread-safe）的核心間通訊：

### 核心 0 (Core 0) —— 硬體監控與隱私防線 (高即時性)
1. **Task A: 環境防災監控 (優先權: 高)**
   - 每 10ms 輪詢溫濕度與煙霧數值。若判定火災，釋放 `Semaphore` 解鎖相機軟體隱私鎖。
2. **Task B: 聲音即時定位 (優先權: 中)**
   - 監聽聲音感測器，異常時將事件打包進 `Queue` 傳遞至網路端。

### 核心 1 (Core 1) —— 影像處理與網路通訊 (高資源消耗)
3. **Task C: Wi-Fi 與 網頁/Email 通訊 (優先權: 低)**
   - 維持網路連線，接收 Core 0 傳來的 Queue 進行 MQTT 網頁同步（變紅）、發送 Email，並在權限解鎖時控制 OV2640 進行 JPEG 影像傳輸。
